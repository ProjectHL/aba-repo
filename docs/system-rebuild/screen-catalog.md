## Componentes visuales recurrentes

- Cabecera blanca con marca, navegación primaria y avatar circular.
- Superficie gris muy clara, tarjetas blancas, bordes suaves y radio medio.
- Azul para adquisición/acciones primarias, rojo para reducción/incorrecto, verde para correcto/activo.
- Formularios largos dentro de diálogos con scroll.
- Pestañas horizontales dentro del detalle del cliente.
- Botones de acción con icono y texto; estados vacíos con instrucciones.
