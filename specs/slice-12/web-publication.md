# Slice 12 / Publicación

No se publica ni se crea hosting. El candidato previo de Slice 11 queda supersedido localmente
hasta repetir build y preflight tras este cambio. Se conservan staging, noindex, no-store, CSP,
HSTS, fallback SPA y el gate de autorización explícita de despliegue.
La dependencia de PDF y el nuevo candidato local deberán medirse y pasar el preflight antes de que
Slice 11 pueda volver a considerar una publicación privada.
